# setlist-tube.fm

Paste a [setlist.fm](https://www.setlist.fm) show link and get a YouTube
playlist of everything that was played. Each song is matched on YouTube Music,
and the result opens as a temporary YouTube playlist, no account needed.
Try it at **https://setlist-tube.onrender.com**.

How it works: [details.md](details.md). Running, developing and deploying:
[deploy.md](deploy.md).
